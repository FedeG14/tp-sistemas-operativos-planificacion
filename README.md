# Simulador de Planificación de Procesos

Trabajo Integrador de Sistemas Operativos — Opción 1.

## Requisitos
- Python 3.8 o superior.
- No requiere instalar bibliotecas externas.

## Ejecución
Abrir una terminal en esta carpeta y ejecutar:

```bash
python main.py
```

## Funcionalidades
- Estructura PCB con PID, nombre, prioridad, llegada, ráfaga y estado.
- Simulación de FCFS y SJF no expropiativo.
- Cálculo de espera y turnaround (retorno).
- Diagrama de Gantt en texto.
- Comparación de promedios.

Los tiempos son unidades simuladas, no segundos reales de CPU.
